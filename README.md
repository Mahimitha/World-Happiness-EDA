# World Happiness EDA Project

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the World Happiness Report 2019 dataset.

## Dataset
World Happiness Report 2019

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Data Loading
- Missing Value Analysis
- Top 10 Happiest Countries
- Bottom 10 Least Happy Countries
- Average Happiness Score Analysis
- GDP vs Happiness Correlation
- Life Expectancy vs Happiness Correlation

## Visualizations
- Bar Chart
- Line Chart
- Histogram
- Scatter Plot
- Pie Chart
- Heatmap

## Key Findings
- Finland was the happiest country in 2019.
- South Sudan had the lowest happiness score.
- GDP per capita strongly influences happiness.
- Healthy life expectancy is positively related to happiness.
